# Contributing

## Before you start

Read the root [`README.md`](README.md) to see which layer you're touching:

- `Coforge AI-Native Mortgage Demo.html` / `mvp/index.html` — static, no build step
- `poc/` — the working agentic slice; see [`poc/README.md`](poc/README.md) for
  the full architecture and design rationale before changing agent, tool, or
  policy code
- `azure-web-app/` — deployment reference notes, not application code

## Setup

Follow the [POC setup steps](README.md#2-poc--agentic-backend--frontend) in
the root README to get the backend and frontend running locally.

## Secrets

Never commit `poc/.env` or any real API key. If you add a new environment
variable, add it to `poc/.env.example` with a placeholder value, not the real
one, and update `poc/.gitignore` if it needs a new pattern excluded.

## Making changes

- Keep the three layers independent — don't add a dependency from the static
  HTML files or `mvp/` onto `poc/`, or vice versa.
- Changes to `poc/backend/app/` should keep the separation of duties intact:
  an agent that raises a finding must not also hold a repair tool, and no
  agent chooses its own disposition lane (that's `policy.decide_disposition()`,
  plain Python, not a model). See "The three rules this codebase exists to
  keep" in [`poc/README.md`](poc/README.md) before changing agent/tool/policy
  code.
- If you change a `requirements*.txt` in `poc/backend/`, re-resolve in a clean
  venv and regenerate both lock files — see the instructions at the top of
  each `.lock.txt` file.
- Re-verify the loan-limit constants in `poc/backend/app/market_data.py` if
  it's a new calendar year — see the RESEARCHED/ESTIMATED notes there.

## Tests

```bash
cd poc/backend && pytest
cd poc/frontend && npm test
```

Run `python scripts/verify_synthetic_data.py` after any change to the
synthetic data generator (`poc/scripts/generate_synthetic_data.py`).

## Commits and PRs

- Keep commits scoped to one logical change.
- Describe *why* a change was made, not just what changed — the code already
  shows what changed.
- Don't commit generated artifacts: `node_modules/`, `frontend/dist/`,
  `__pycache__/`, `*.db*`, or anything under `poc/backend/data/documents/`
  regenerated by the synthetic data script.
