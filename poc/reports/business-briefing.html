Meet Your AI Loan Team

A business briefing on the AI system now speeding up loan review — what it does, where people stay in control, and why it matters.

The problem

A loan file is a lot to read, every single time

A single file can hold a dozen documents and hundreds of numbers that all have to agree with each other and with the program's rules — income against the paystub, the paystub against the W-2, the appraisal against the contract, the identity documents against each other. Checking all of it by hand is slow, repetitive, and exactly the kind of task where a tired reviewer misses a line on a Friday afternoon. That delay is what this system is built to close, without lowering the bar on what gets checked.

How it works

A file moves through five checkpoints

Four AI agents do the reading and checking. Every one of them has one job and cannot do anyone else's — the agent that finds a problem is never the one allowed to fix it.

Nothing here waits on a button anymore. Picking up a file to work on is what starts the checkpoints that file still needs — see “What’s new” below.
Meet the agents

Four specialists, one job each

Each agent is deliberately narrow. That's not a limitation — it's the safeguard: the same agent can never both raise a finding and clear it, so nothing gets to mark its own work.

Checkpoint 1

Document Intake Agent

Reads every paystub, W-2, bank statement, appraisal, and disclosure in the file and pulls the key numbers — income, assets, property value, identity — into one place.

Can't do: decide anything about the loan. It only reads and records.
Checkpoint 2

Validation Agent

Checks the file's numbers against the actual rules for that loan program — debt ratios, loan-to-value, income documentation — and flags anything that doesn't line up, with its reasoning attached.

Can't do: fix anything it finds. It can only flag.
Checkpoint 3

Processing Agent

Clears the simple, low-risk findings automatically and can order routine services like an appraisal or a title search.

Can't do: touch anything involving money, a borrower, or judgment without a person confirming it first.
Checkpoint 4

Summarizer Agent

Reads the whole file and everything the other three agents found, then writes a short, plain-English brief for the underwriter: what's solid, what to look at twice.

Can't do: change anything in the file. It only reports.
Who's keeping watch

The guardrails, not the prompts

None of the promises below rely on an agent choosing to behave. Each one is a fixed rule the system enforces on every action, automatically.

1
Confidence doesn't decide alone. The AI reports how sure it is; a separate, fixed set of lending rules — not the AI itself — decides whether that's enough to act without a person.
2
Some things always go to a person, no matter how confident the AI is: income surprises, debt or value breaches, anything about someone's identity or the title of the property, and anything that looks like an attempt to manipulate the system.
3
A second pair of eyes on the sensitive calls. For the most sensitive findings, an analyst can only propose a fix — a supervisor has to approve it before it takes effect.
4
Every action is written down, permanently. Whether it was the AI or a person, every step is recorded in a record that can't be edited or deleted — so anyone can see exactly what happened to a file, and when.
5
Each person sees only their own job. An analyst works their own queue, only a supervisor approves sign-offs, only an underwriter renders a decision — enforced by the system itself, not just hidden from the screen.
What's new

Two changes that remove busywork

Just added

Picking up a file starts the work

There used to be an extra step: pick the file, then separately press a button to run the agents. Now, opening a file runs exactly the checkpoints it still needs — nothing more. A file that's already clean, or already sitting with a person, is left alone instead of being re-checked for no reason.

The AI's write-up no longer disappears

The Summarizer's brief used to only exist for the moment it was written, then vanish. It's now saved with the file and shown on the underwriter's screen — a short preview by default, with the full write-up one click away when it's needed.

The benefit, in short

What changes for the people doing the work

Files move faster

A clean file reaches the underwriter in minutes, already read and checked — instead of sitting in a queue until someone has time to open it.

The same checks, every time

Every file gets the same rules applied the same way, whether it's the first file of the day or the fortieth.

Judgment stays with people

The AI only acts on the mechanical, low-risk items. Anything that requires experience or discretion still goes to a person, by design.

Nothing is hard to explain later

Every action — AI or human — is on the record. If a regulator or an auditor asks "what happened on this file," the answer is already written down.

This covers the first slice of the loan lifecycle — intake through the underwriting decision. The same approach is planned to extend to closing, funding, and post-closing review as the system grows.
